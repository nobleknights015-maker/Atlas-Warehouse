# Unit 09 — independently painted static sprite study (Round 01)

**Status: training; artistic quality gate NOT PASSED.** The Founder moved current practice from complex Relay portraits to a simpler starter Sleeper Frame Unit 09. Do not upload supplied reference sheets to this public warehouse.

## Reference design targets
Overlapping asymmetric off-white helmet and armor plates, narrow violet visor, functional side-head modules, dark articulated underframe, red cabling, 09 shoulder mark, separated arms/fingers/hips/knees/ankles/feet. Lean silhouette is the quality benchmark. The frame is humanoid, not bear-shaped.

## Actual exercises
1. Isolated first front idle pose from user-supplied sprite sheet (source crop 125x321; 160x352 transparent). Source extraction, NOT original drawing.
2. Tested naive 32/64/96-color reduction: global quantization weakened violet visor and leg lights. A reserved violet ramp fixed this, but first color choice oversaturated the glow; a source-near second ramp produced a more faithful 64-color pass. Color processing, NOT original drawing.
3. Separately painted a NEW static standing sprite from a blank 128x216 canvas using manually authored integer-pixel raster operations and 16 RGB colors, binary 0/255 alpha, both arms and legs, side-head tech, plates, cable highlights, narrow visor, and 09 shoulder stencil. No image generation, pixelization or tracing of the reference was used for this independent exercise.

## Critical review
Despite clean transparency and complete basic anatomy, the independently drawn sprite remains too stout/short-legged compared with the supplied source. Chassis armor is too flat, helmet layers are overly simplified, and some panels lack directional volume. This is a construction sketch; artistic quality gate failed. Numeric tests do NOT imply an aesthetically strong sprite.

## Next exercise
Redraw legs/hips from blank pixels to match the original lean proportions at native resolution, then practice angular bone-white plate interlocks and source-consistent directional lighting. Only after approving a static base should animation, overgrowth and Echo glitch behaviors be attempted on this character. Retain all previous curriculum in parallel.
