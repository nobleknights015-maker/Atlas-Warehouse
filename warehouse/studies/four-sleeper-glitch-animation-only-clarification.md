# Four selectable Sleepers — glitch ANIMATIONS, not redesigns

**Founder correction — November 11, 2026. This replaces older suggestions to add extra age/damage to the four approved playable designs.**

## Locked appearances and identities
- Four Founder-supplied portraits already depict old, visibly damaged Sleeper Frames.
- The four approved sprite-turnaround visual references match those identities. Preserve existing armor wear, clothing damage, visor/chest/side-head displays, hair/helmet silhouettes and each character's established purple/cyan lighting.
- DO NOT age them more, add random corrosion or overgrowth, replace their art, or make them look like generic Echo Frames.
- Selection portrait A/B/C/D must map to the corresponding playable sprite A/B/C/D, including in saves.

## Requested Echo-style problem behaviors as separate animation clips / effects
1. **Core glitch**: chest/core light skips, pulses unevenly, flickers or momentarily desynchronizes, then returns to baseline.
2. **System fault**: visor/side-head displays glitch, flicker or momentarily dim; sparse localized visual distortion, never full-frame noise that loses identity.
3. **Actuator hiccup**: brief involuntary arm/shoulder/head stutter or joint lag, with connected limbs and consistent root/feet.
4. **Severe desync / recovery**: rare momentary freeze, stagger or misalignment followed by a believable stabilization and recovery to the idle/walk cycle.
5. **Optional memory disruption**: subtle inconsistent signal/readout behavior only when appropriate to the story.

These are **animations layered on the pre-existing designs**, not permanent new static damage. Character-specific variations may reflect established design and existing damage, without inventing new canon. Do not assert all four are classified Echo Frames merely because malfunction animations borrow Echo characteristics.

## Development/QA
Produce/validate the four static and ordinary idle/walk sprites at real engine scale first; then author separate malfunction clips/overlays and test them against normal playback and mobile runtime. At native pixel size inspect:
- original identity, silhouette and palette preserved;
- no torn or disconnected limbs unless a deliberate, approved visual effect;
- consistent feet/root registration and chest/core anchor;
- non-repetitive timings and clean return to idle;
- visual accessibility/readability, no incessant flash.

**Only production-approved assets after on-device confirmation.** Source/derived character art stays private; this public Warehouse file describes methods only.
